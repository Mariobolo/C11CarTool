# C11 车控 · C11CarTool

> 专为**零跑 C11** 打造的第三方车机控制工具。
> **本软件免费、开源，无条件供广大 C11 车友共享使用，欢迎安装、转发与二次开发。**

一个运行在零跑 C11 车机（Android 9）上的 App：网格化桌面实时展示车辆信息、一键车控、手机扫码遥控、一键诊断与日志导出，全部功能前端直达。

---

## ✨ 功能特性

- **网格化桌面**：主页上下纵向滚动，小模块拼接；宽度自适应（全屏 / 1/2 宽 / 1/3 宽自动换行）
- **统一小模块**：数值 / 步进 / 开关 / 动作四类，玻璃质感，字号与触摸目标对齐车机设计规范
- **车辆信息**：电量、续航、电压、电流、功率、车速、档位、车外温度、胎压胎温、车门 / 舱盖、PM2.5、四路音量，5s 自动刷新
- **车辆控制**：空调（温度 / 风量 / AC / 最大制冷 / 循环 / 除霜 / 模式）、车窗（自定义开度）、儿童锁、后备箱、全车灯光、车门锁
- **手机扫码测控**：App 内置 Web 服务，同一 WiFi 下手机扫码即可遥控车辆、查看数据与日志
- **一键诊断 / 日志导出**：环境、权限、端口、各通道自测一次采集，便于反馈与排障
- **全车信号清单 / 全部车控页**：搜索、折叠、多通道并列，不藏功能、不放假数据

## 🚗 适用环境

- 零跑 C11（2023 款），Android 9（API 28）
- 中控横屏 1920×1080；支持全屏、1/2 宽度、1/3 宽度三种显示状态

## ⚡ 快速开始

1. 到 **[Releases](../../releases)** 下载最新 `C11CarTool_v*_debug.apk`
2. 车机上安装（需允许"未知来源"）
3. 打开 App，按界面提示连接 ADB（车机系统演示入口）
4. 主页查看车辆信息、进行车控；点 **「📱 扫码测控」**，手机连同一 WiFi 扫码即可遥控

## 📱 手机扫码测控

App 启动后自动开启 Web 服务，弹窗显示地址与二维码。手机与车机连同一 WiFi、扫码打开网页，即可在手机上看车辆数据、按车控按钮、查看 / 复制日志，方便在电脑前操作与反馈。

## 🩺 一键诊断

点「一键诊断」自动采集：ADB 连接与权限、端口监听、各车控通道自测、系统环境信息，可直接导出报告或日志，帮助定位问题、减少来回猜测。

## 🔧 实现说明（车控通道）

项目基于对车机升级包与实车日志的分析，采用多通道架构；空调座舱（settings global）、部分语音广播、Rightware 车锁等已在实机标定，少数通道（音量范围、空调模式枚举、远光等）仍标注 `⚠ 待真机标定`。未找到有效通道的功能（如前机盖控制）不放假按钮，仅作只读或说明。

## 📊 数据与车控通道（汇总）

- **settings global（可读写，真机实证）**：空调开关 / 风量 / 运行模式 / 循环 / 前后除霜 / 主副温度、童锁、车窗锁、哨兵、四路音量（C11_MUSIC / NAVI / CALL / SPEECH）。
- **logcat（只读）**：电压(3130) / 电流(3131) / 电量(3162) / 续航(301) / 车速(1108) / 档位(1110) / 车外温(33110)、四车门(9123–9126) / 后备箱(9127) / 前机盖(9128)、四车窗(21180–21183)。
- **讯飞 handMessage**：空调开关、360、童锁、后备箱、四车窗开度。
- **Rightware**：锁车 / 解锁（Android 9 需 start-foreground-service）。
- **旧语音广播**：最大制冷、灯光。
- **温度口径（切勿混淆）**：settings `strCar1409/1410` = ℃×2（52→26℃）；logcat `28110/28111` = 直接℃。
- 待真机标定：空调运行模式 raw=3、"通风"对应值、循环"自动"=2、车窗 21181/2/3、部分语音实体名。

## ✅ 上机验证清单（精简）

1. 打开 App 自动连 ADB（最多 6 次），连接后保持、状态显示 uid=2000；重启后看日志"授权固化:"行。
2. 失败命令不卡死；四路音量滑块松手不卡死且生效；空调界面能弹出。
3. 回归：空调开关 / 温度 / 风量 / 循环 / 除霜、全车灯光、童锁、后备箱、四车窗方向与开度、锁车 / 解锁、360、四阅读灯。
4. 数据有值并缓存保留，读不到明确标 `--`；手机连同一 WiFi 扫码可遥控 / 看日志（无 401）。
5. 回传：App 导出日志、adb logcat、Web 截图、wlan0 IP、标定结果。
